# 🎬 Film Production Management System

A PostgreSQL database project for managing a film production system, accompanied by a C# Windows Forms application developed using the Database-First approach as a client for performing CRUD operations.

---

## 🛠 Technologies

- C#
- WinForms
- PostgreSQL
- Entity Framework (Database-First)

---

## ✨ Features

- Create, read, update and delete records
- PostgreSQL relational database
- Database-First development
- Stored procedures
- Triggers
- Search functionality

---

## ▶️ Running the Project
To run this project:

1. Clone this repository.
2. Create a PostgreSQL database named **FilmProduction**.
3. Import the `filmProduction.sql` file into the database.
4. Open `filmProductionApp/vtys/vtys.sln` in Visual Studio.
5. Update all PostgreSQL connection strings in the `.cs` files with your local PostgreSQL credentials.
6. Build and run the application.
